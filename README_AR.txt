نسخة عرض واجهات Elite Skills Academy للنشر على GitHub Pages

مهم: هذه نسخة Front-end تجريبية ثابتة لعرض شكل الصفحات والتنقل بينها فقط.
لا يوجد اتصال بقاعدة بيانات، ولا يتم حفظ التسجيل أو تسجيل الدخول أو طلبات الاشتراك.
المشروع التشغيلي الأصلي PHP + MySQL ويحتاج استضافة تدعم PHP وMySQL.

النشر السريع:
1) أنشئي Repository جديدًا على GitHub باسم elite-skills-demo.
2) اجعليه Public.
3) ارفعي كل محتويات هذا المجلد إلى جذر المستودع (Upload files ثم Commit changes).
4) افتحي Settings > Pages.
5) تحت Build and deployment اختاري Deploy from a branch.
6) اختاري Branch: main والمجلد: /(root)، ثم Save.
7) انتظري حتى يظهر رابط GitHub Pages في صفحة Pages.
8) افتحي الرابط واختبريه من نافذة خاصة أو موبايل.

ابدئي العرض من index.html ثم جرّبي الكورسات، التسجيل، الدخول، ولوحات الأدوار.
